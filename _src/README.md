# Сайт Kamilovs Clinic: как устроен и как править

Статический сайт на GitHub Pages (ветка `main`, корень репозитория). Фреймворков
и зависимостей нет. HTML в корне **собирается** из этой папки, руками его не правят.

```bash
node _src/build.mjs                       # собрать страницы и словарь
python -m http.server 5178                # посмотреть на http://localhost:5178
```

Папка `_src` на сайт не публикуется: Jekyll на GitHub Pages пропускает папки с подчёркиванием.

## Где что менять

| Что нужно | Где |
| --- | --- |
| Тексты, перевод | `_src/i18n.mjs` (ключ обязан быть и в `ru`, и в `uz`, иначе сборка упадёт) |
| Услуги | `_src/data/services.mjs` |
| Врачи | `_src/data/doctors.mjs`, фото — см. ниже |
| Телефон, Telegram, Instagram, реквизиты, лицензия, Метрика | `js/kc-config.js` |
| Разметка секций главной | `_src/pages/home.mjs` |
| Шапка, футер, форма, окно записи | `_src/components.mjs` |
| Цвета, отступы, подключение шрифтов | `css/kc-tokens.css` |
| Состав шрифтов | `_src/tools/make_fonts.py` |
| Обложка для соцсетей | `_src/tools/og-cover.html` |
| Текст политики | `_src/content/privacy.html` |

`js/kc-config.js` собирать не нужно: он подключается как есть.

## Небо

`js/kc-sky.js` раскрашивает первый экран, блок записи и шапки страниц по времени
Ташкента. Цвета задаются таблицей `KEYS`: при правке проверяйте, что верх и середина
неба остаются достаточно тёмными для белого текста (контраст от 4.5:1).

## Фото врачей

Портреты-исходники лежат в `_src/assets/doctors`, на сайт идут вырезанные версии
`images/doctors/cut-N.webp`. Новый врач:

1. Положите портрет в `_src/assets/doctors/doctor-N.webp`.
2. Добавьте N в `HEADS` в `_src/tools/make_doctor_cutouts.py`.
3. Запустите скрипт (инструкция в его начале) и добавьте врача в `_src/data/doctors.mjs`.

Нейросеть только отделяет человека от фона, лицо и одежда не меняются.

## Фото клиники

На сайте только настоящие снимки: `_src/tools/make_room_photos.py` делает из
`_src/assets` кадры для главной. Стоковых фото нет намеренно: пациент должен видеть
ту клинику, в которую придёт. Новые снимки добавляются в список `JOBS` этого скрипта.

## Заявки

Формы отправляются на `https://kamilovsclinic-backend.onrender.com/lead/`. Каждая
такая отправка создаёт настоящую заявку и сообщение администраторам в Telegram,
поэтому форму на сайте проверяют с подменённым `fetch`, а не настоящей отправкой.
