# Сайт Kamilovs Clinic: как устроен и как править

Статический сайт на GitHub Pages (ветка `main`, корень репозитория). Фреймворков
и зависимостей нет. HTML в корне **собирается** из этой папки, руками его не правят.

```bash
node _src/build.mjs                       # собрать страницы и словарь
python -m http.server 5178                # посмотреть на http://localhost:5178
```

Папка `_src` на сайт не публикуется: Jekyll на GitHub Pages пропускает папки с подчёркиванием.

## Где что менять

| Что нужно | Где |
| --- | --- |
| Тексты, перевод | `_src/i18n.mjs` (ключ обязан быть и в `ru`, и в `uz`, иначе сборка упадёт) |
| Услуги | `_src/data/services.mjs` |
| Врачи | `_src/data/doctors.mjs`, фото — см. ниже |
| Телефон, Telegram, Instagram, реквизиты, лицензия, Метрика | `js/kc-config.js` |
| Разметка секций главной | `_src/pages/home.mjs` |
| Шапка, футер, форма, окно записи | `_src/components.mjs` |
| Цвета, отступы, подключение шрифтов | `css/kc-tokens.css` |
| Состав шрифтов | `_src/tools/make_fonts.py` |
| Обложка для соцсетей | `_src/tools/og-cover.html` |
| Текст политики | `_src/content/privacy.html` |

`js/kc-config.js` собирать не нужно: он подключается как есть.

## Небо

`js/kc-sky.js` раскрашивает первый экран, блок записи и шапки страниц по времени
Ташкента. Цвета задаются таблицей `KEYS`: при правке проверяйте, что верх и середина
неба остаются достаточно тёмными для белого текста (контраст от 4.5:1).

## Фото врачей

Портреты-исходники лежат в `_src/assets/doctors`, на сайт идут вырезанные версии
`images/doctors/cut-N.webp`. Новый врач:

1. Положите портрет в `_src/assets/doctors/doctor-N.webp`.
2. Добавьте N в `HEADS` в `_src/tools/make_doctor_cutouts.py`.
3. Запустите скрипт (инструкция в его начале) и добавьте врача в `_src/data/doctors.mjs`.

Нейросеть только отделяет человека от фона, лицо и одежда не меняются.

## Фото клиники

На сайте только настоящие снимки: `_src/tools/make_room_photos.py` делает из
`_src/assets` кадры для главной. Стоковых фото нет намеренно: пациент должен видеть
ту клинику, в которую придёт. Новые снимки добавляются в список `JOBS` этого скрипта.

## 3D

Объёмные сцены — надстройка. Страница сначала показывается в обычном виде, 3D
«проявляется» поверх и только там, где устройство его потянет. Решает это
`js/kc-3d.js`: нужна настоящая видеокарта, от 4 ядер и 4 ГБ памяти, без экономии
трафика и без настройки «меньше движения». Сцена первого экрана на телефонах
включается только при 8 ГБ памяти. Иначе остаётся обычная версия, а на `<html>`
ставится класс `kc-no3d`.

3D подключается не сразу, а через 2,4 секунды после загрузки страницы или при
первом движении мыши (`SETTLE_MS` в `js/kc-3d.js`), и готовится мелкими шагами с
паузами. Поэтому скорость загрузки страницы от 3D не зависит. Не убирайте паузы
`breathe()` в `js/3d/hero.js` и `js/3d/mark.js`: без них страница будет замирать
на время подготовки сцены.

| Что | Где |
| --- | --- |
| Первый экран: небо, арки, врачи | `js/3d/hero.js` |
| Объёмный знак клиники и зуб в плитке | `js/3d/mark.js`, атрибут `data-kc-mark` |
| Объёмная фотография кабинета | `js/3d/depth.js`, атрибут `data-kc-depth` |
| Наклон карточек за курсором | `initTilt` в `js/kc-ui.js`, атрибут `data-tilt` |
| Плавный переход между страницами | `@view-transition` в `css/kc-tokens.css` |
| Движок three.js, урезанная сборка | `js/vendor/three.kc.min.js` |

Сцена первого экрана берёт размеры и положение арок из вёрстки и цвета неба из
`KC.sky` (`js/kc-sky.js`), поэтому обычная и объёмная версии совпадают.

Движок собран из списка в `_src/tools/three-entry.mjs`. Понадобился новый класс
three.js — добавьте его в список и пересоберите (в любой временной папке):

```bash
npm i three@0.187.0 esbuild
cp путь/к/сайту/_src/tools/three-entry.mjs entry.mjs
npx esbuild entry.mjs --bundle --minify --format=esm --target=es2020 --legal-comments=none "--banner:js=/*! three.js r187 | MIT License | Copyright 2010-2026 three.js authors | https://threejs.org | subset, see _src/tools/three-entry.mjs */" --outfile=путь/к/сайту/js/vendor/three.kc.min.js
```

После правок 3D проверяйте три режима: обычный, без WebGL и «меньше движения».

## Видео и объёмное фото

Настоящей видеосъёмки клиники пока нет. Ролик «Клиника изнутри» собран из двух
настоящих снимков кабинетов: нейросеть оценивает, что в кадре ближе, а что дальше,
и по этой карте камера «проезжает» по фотографии. Дорисованного в кадре нет, на
странице об этом сказано прямо.

```bash
python _src/tools/make_depth_maps.py путь/к/depth_anything_v2_small.onnx   # карты глубины в _src/assets/depth
python _src/tools/make_room_photos.py                                      # кадры и карта глубины для главной
python _src/tools/make_tour_video.py путь/к/ffmpeg                         # media/clinic-tour.mp4, .webm и обложка
```

Когда появится настоящая съёмка, замените файлы в `media`, обложку
`images/tour-poster.webp` и время начала глав в `TOUR` (`_src/pages/home.mjs`).
Видео включается само, только пока его видно, и не включается при экономии трафика
и настройке «меньше движения».

## Заявки

Формы отправляются на `https://kamilovsclinic-backend.onrender.com/lead/`. Каждая
такая отправка создаёт настоящую заявку и сообщение администраторам в Telegram,
поэтому форму на сайте проверяют с перехваченным запросом, а не настоящей отправкой.
